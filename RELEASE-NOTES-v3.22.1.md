# ProTrackAI v3.22.1: the executive report is the home page (October 2026)

After signing in, ProTrackAI opens **Home → Executive report (released)** for every role that has it in its menu: super admin, executives, regional and portfolio managers, planning and costing engineers, and project managers.

The other roles keep their own home page, since the executive report is not in their menu:
- site engineers and site managers: the live summary
- foremen: their daily reports
- read-only users: the dashboard

The executive report shows the latest released period. When that period is held (v3.22), it says so, with a link to the reporting status.

Switching *Acting as* opens the same home page. A screen the super admin has hidden from a role (Settings → Roles and rights → Screens by role) is never used as its home page.

No server change.
